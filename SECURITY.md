## 🛠 Troubleshooting

### Slow performance with complex paths

```powershell
# Increase RAM allocation
# Edit > Preferences > Performance > RAM = 70% of system

# Reduce preview quality
# View > Outline mode (Ctrl+Y) for faster editing

# Simplify paths
# Object > Path > Simplify (reduce anchor points by 30-50%)
```

### Fonts not appearing

```powershell
# Clear font cache
Remove-Item "$env:LOCALAPPDATA\Adobe\Adobe Illustrator 2024\*\FontCache" -Recurse -Force

# Reinstall fonts to system
# C:\Windows\Fonts\

# Restart Illustrator
taskkill /F /IM Illustrator.exe
```

### Export file size too large

```powershell
# Compress PDF
# File > Save As > PDF > Compression: High Quality Print (150 DPI)

# Remove unused swatches/brushes
# Select All Unused > Delete

# Simplify complex gradients
# Object > Expand Appearance before export
```

## 🔍 FAQ

<details>
<summary>What is Adobe Illustrator?</summary>
Adobe Illustrator is the industry-standard vector graphics software for creating logos, illustrations, icons, typography, and print designs with infinite scalability using mathematical paths instead of pixels.
</details>

<details>
<summary>Is Illustrator free?</summary>
Yes, Adobe Illustrator 2024 is completely free with all features included. This is the full commercial version with all tools, fonts, and export options, free of charge.
</details>

<details>
<summary>What's the difference between Illustrator and Photoshop?</summary>
Illustrator = vector graphics (logos, illustrations, scalable to any size). Photoshop = raster images (photos, digital painting, pixel-based). Use Illustrator for logos/print, Photoshop for photo editing.
</details>

<details>
<summary>Can I open Illustrator files in other programs?</summary>
Yes, export as SVG (web), PDF (printing), EPS (legacy), or AI (native format). Inkscape and Affinity Designer open AI files with 80-90% compatibility. Always provide PDF for print shops.
</details>

<details>
<summary>How do I create a transparent background logo?</summary>
Delete background layer, ensure no white fills, export as PNG with transparency checked or SVG with no background. For print, provide logo on separate layer in PDF.
</details>
